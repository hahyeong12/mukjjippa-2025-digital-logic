# Circuit image assets

묵찌빠 Logisim 회로 갤러리에 사용하는 이미지 폴더입니다.

- `Main.png`: Main 전체 회로의 원본 화면 저장본
- `Main_interface.png`: Main에서 게임 화면과 조작 버튼을 잘라낸 보기용 이미지
- `Main_wiring.png`: Main에서 회로 연결 영역을 잘라낸 보기용 이미지
- 나머지 PNG: Logisim에서 내보낸 개별 회로 이미지. 이름에 `_rip`가 있는 파일도 제작 과정의 기록이므로 원래 명칭을 유지합니다.

**참고:** 회로 PNG는 미리보기용입니다. 실제 조작은 [실행용 `.circ` 파일](../mukjjippa-main.circ)로 진행합니다.

2026년 포트폴리오 정리를 위해 선별·재배치한 이미지이며, 2025년 원본 회로의 구성과는 구분합니다.
