이 화면과 실제 Logisim 회로의 관계

지금 보고 계신 화면은 규칙 체험용 웹 재구현입니다. 실제 수업 작품은 Logisim-evolution에서 FSM, D Flip-Flop, Score Counter, LED 327개를 연결한 회로입니다. 원본은 위의 ‘원본 회로 열기’에서 확인할 수 있습니다.

프로젝트 배경 — 교수님의 “하루 만에 끝낼 수 없는 노력과 공부의 흔적”이라는 요구를 듣고, 평범한 가위바위보를 오히려 상태 저장이 필요한 묵찌빠로 확장했습니다. 디지털논리시스템 텀프로젝트 만점을 받았습니다.
